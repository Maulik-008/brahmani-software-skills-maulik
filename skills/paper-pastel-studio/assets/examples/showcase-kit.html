Paper & Pastel

A white canvas carrying a small, curated family of pastel-tinted cards. Depth comes from hairline borders and a one-hue surface ramp, not shadows. Colour is spent by category, never for decoration. The one filled button is ink on paper. This page is built entirely in the system, so every surface below is the real recipe.

// colour

Five colour jobs, no more

Canvas, ink, line, brand accent, and category colour. Greys are blue-tinted (hue ~220), never neutral. If a colour you want does not map to one of these jobs, stop.

// type

Geist Sans, Geist Mono, nothing else

Sans for everything readable. Mono for eyebrows, labels, meta, stat numbers and the wordmark, always uppercase and wide-tracked. The display scale is oversized with very tight tracking, used for headlines only.

// motion

Quiet, brief, once

framer-motion in the real app. Hover the card to feel the standard lift. Everything sits at a visible resting state and respects prefers-reduced-motion.

Hover-lift

translateY(-3px) + tinted shadow built from --shadow-color at low alpha. No grey drop shadow anywhere.

Reveal recipe

initial:  { opacity: 0, y: 20 }
inView:   { opacity: 1, y: 0 }   once, margin -60px
duration: 0.4 to 0.7   ease [0.22, 1, 0.36, 1]
stagger:  0.06 per child
